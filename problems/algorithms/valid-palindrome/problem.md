# Valid Palindrome

Given a string `s`, return `true` if it is a palindrome after converting uppercase letters to lowercase and removing all non-alphanumeric characters. Otherwise return `false`.

Examples: `"A man, a plan, a canal: Panama"` returns `true`; `"race a car"` returns `false`; `" "` returns `true`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
