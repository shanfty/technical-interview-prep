# Word Search

Given an `m x n` grid of characters and a string `word`, return `true` if the word exists in the grid. The word must be formed from sequentially adjacent cells horizontally or vertically, and a cell may not be used more than once in the same word.

Examples: board `[[A,B,C,E],[S,F,C,S],[A,D,E,E]]`, word `"ABCCED"` returns `true`; word `"SEE"` returns `true`; word `"ABCB"` returns `false`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
