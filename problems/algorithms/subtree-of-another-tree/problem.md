# Subtree of Another Tree

Given the roots of two binary trees `root` and `subRoot`, return `true` if `subRoot` is a subtree of `root`. A subtree consists of a node and all of its descendants; an empty tree is a subtree of every tree.

Examples: `root = [3,4,5,1,2]`, `subRoot = [4,1,2]` returns `true`; `subRoot = [4,1,2,0]` returns `false`.
