# Diameter of Binary Tree

Given the root of a binary tree, return the length of the diameter. The diameter is the number of edges on the longest path between any two nodes. The path may or may not pass through the root.

Examples: `[1,2,3,4,5]` has diameter `3`; a single-node tree has diameter `0`.
