# Remove Nth Node From End of List

Given the head of a linked list, remove the `n`th node from the end and return the head of the resulting list.

Examples: `[1,2,3,4,5]`, `n = 2` becomes `[1,2,3,5]`; `[1]`, `n = 1` becomes `[]`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
