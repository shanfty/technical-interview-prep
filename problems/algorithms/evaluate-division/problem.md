# Evaluate Division

You are given equations such as `a / b = 2.0` and queries such as `a / c`. Return the value of each query. If a query cannot be determined from the equations, return `-1.0`.

Examples: equations `a/b = 2.0`, `b/c = 3.0` make `a/c = 6.0`, `c/a = 1/6.0`, and an unknown variable query equal to `-1.0`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
