# Jump Game

Given an integer array `nums`, you start at index `0`, and `nums[i]` is the maximum jump length from index `i`. Return `true` if you can reach the last index, otherwise return `false`.

Examples: `[2,3,1,1,4]` returns `true`; `[3,2,1,0,4]` returns `false`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
