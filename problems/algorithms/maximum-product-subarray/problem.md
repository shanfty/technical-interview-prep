# Maximum Product Subarray

Given an integer array `nums`, find a contiguous non-empty subarray that has the largest product and return the product.

Examples: `[2,3,-2,4]` returns `6`; `[-2,0,-1]` returns `0`; `[-2,3,-4]` returns `24`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
