# Palindrome Partitioning

Given a string `s`, partition it so that every substring in every partition is a palindrome. Return all possible palindrome partitionings in any order.

Example: `"aab"` returns `[["a","a","b"],["aa","b"]]`; `"a"` returns `[["a"]]`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
