# Single Number

Given a non-empty array of integers where every element appears exactly twice except for one element, return the element that appears once.

Examples: `[2,2,1]` returns `1`; `[4,1,2,1,2]` returns `4`; `[1]` returns `1`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
