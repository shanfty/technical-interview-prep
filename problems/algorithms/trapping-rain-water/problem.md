# Trapping Rain Water

Given an elevation map represented by non-negative bar heights of width one, compute how much rainwater can be trapped after raining.

Examples: `[0,1,0,2,1,0,1,3,2,1,2,1]` returns `6`; `[4,2,0,3,2,5]` returns `9`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
