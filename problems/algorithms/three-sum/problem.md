# 3Sum

Given an integer array `nums`, return all unique triplets `[nums[i], nums[j], nums[k]]` whose values sum to zero. Indices must be distinct. The triplets and their ordering may be returned in any order, and duplicate triplets are not allowed.

Examples: `[-1,0,1,2,-1,-4]` returns `[[-1,-1,2],[-1,0,1]]`; `[0,1,1]` returns `[]`; `[0,0,0]` returns `[[0,0,0]]`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
