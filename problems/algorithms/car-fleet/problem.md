# Car Fleet

There are cars traveling toward a target on a one-lane road. Each car has a starting position and speed. A car cannot pass another; when it catches a slower car, it travels at that car's speed. Return the number of car fleets that arrive at the target.

Examples: target `12`, positions `[10,8,0,5,3]`, speeds `[2,4,1,1,3]` returns `3`; target `10`, positions `[3]`, speeds `[3]` returns `1`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
