# Gas Station

There are `n` gas stations arranged in a circle. `gas[i]` is the fuel available at station `i`, and `cost[i]` is the fuel needed to travel from station `i` to the next station. Return the starting station index that allows a complete clockwise circuit, or `-1` if none exists. If a solution exists, it is unique.

Examples: `gas = [1,2,3,4,5]`, `cost = [3,4,5,1,2]` returns `3`; `gas = [2,3,4]`, `cost = [3,4,3]` returns `-1`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
