# Regular Expression Matching

Given an input string `s` and a pattern `p`, implement regular expression matching with support for `.` matching any single character and `*` matching zero or more occurrences of the preceding element. The entire input string must match.

Examples: `s = "aa"`, `p = "a"` returns `false`; `s = "aa"`, `p = "a*"` returns `true`; `s = "ab"`, `p = ".*"` returns `true`.
