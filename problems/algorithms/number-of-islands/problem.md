# Number of Islands

Given an `m x n` grid of `'1'` land and `'0'` water, return the number of islands. An island is formed by horizontally or vertically adjacent land cells and is surrounded by water or the grid boundary.

Examples: `[[1,1,0],[0,1,0],[0,0,1]]` has `2` islands; a grid of all water has `0`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
