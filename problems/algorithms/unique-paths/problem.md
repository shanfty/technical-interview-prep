# Unique Paths

There is a robot on an `m x n` grid. It starts at the top-left cell and can move only right or down. Return the number of possible paths to the bottom-right cell.

Examples: `m = 3`, `n = 7` returns `28`; `m = 3`, `n = 2` returns `3`; a `1 x 1` grid returns `1`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
