# Balanced Binary Tree

Given the root of a binary tree, return `true` if the tree is height-balanced. A binary tree is balanced when the heights of the left and right subtrees of every node differ by no more than one.

Examples: `[3,9,20,null,null,15,7]` is balanced; `[1,2,2,3,3,null,null,4,4]` is not; an empty tree is balanced.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
