# Combination Sum

Given an array of distinct positive integers `candidates` and a target integer, return all unique combinations of candidates that sum to the target. A candidate may be chosen unlimited times. The combinations may be returned in any order.

Examples: candidates `[2,3,6,7]`, target `7` returns `[[2,2,3],[7]]`; candidates `[2,3,5]`, target `8` returns `[[2,2,2,2],[2,3,3],[3,5]]`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
