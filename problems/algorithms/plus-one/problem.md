# Plus One

Given a non-empty array of decimal digits representing a non-negative integer, increment the integer by one and return the resulting digits. The digits are stored from most significant to least significant, and there are no leading zeroes.

Examples: `[1,2,3]` returns `[1,2,4]`; `[4,3,2,1]` returns `[4,3,2,2]`; `[9]` returns `[1,0]`.
