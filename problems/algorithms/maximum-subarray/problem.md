# Maximum Subarray

Given an integer array `nums`, find the contiguous subarray with the largest sum and return its sum. The subarray must be non-empty.

Examples: `[-2,1,-3,4,-1,2,1,-5,4]` returns `6`; `[5,4,-1,7,8]` returns `23`; `[-3,-1,-2]` returns `-1`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
