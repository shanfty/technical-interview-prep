# Serialize and Deserialize Binary Tree

Design an algorithm to serialize a binary tree into a string and deserialize that string back into the original tree. The serialization format is yours to define, but it must preserve node values and null children.

Examples: serializing an empty tree and deserializing it returns an empty tree; a tree with root `1`, left child `2`, and right child `3` must round-trip with the same structure.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
