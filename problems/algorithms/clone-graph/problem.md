# Clone Graph

Given a reference to a node in a connected undirected graph, return a deep copy of the graph. Each node contains an integer value and a list of neighboring nodes. Return `null` when the input is `null`.

The graph has no self-loops, no repeated edges, and node values are unique from `1` through `100`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
