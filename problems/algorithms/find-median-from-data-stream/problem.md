# Find Median from Data Stream

Design a data structure that supports adding integers from a stream and returning the median of all values seen so far. If the count is even, the median is the average of the two middle values.

Example operations: add `1`, add `2`, median is `1.5`; add `3`, median is `2.0`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
