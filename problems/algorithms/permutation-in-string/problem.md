# Permutation in String

Given two strings `s1` and `s2`, return `true` if `s2` contains a permutation of `s1` as a contiguous substring, and `false` otherwise. Assume lowercase English letters.

Examples: `s1 = "ab"`, `s2 = "eidbaooo"` returns `true`; `s1 = "ab"`, `s2 = "eidboaoo"` returns `false`.
