# Target Sum

Given an integer array `nums` and an integer `target`, assign either `+` or `-` before each number and return the number of assignments whose resulting sum equals `target`.

Examples: `[1,1,1,1,1]`, target `3` returns `5`; `[1]`, target `1` returns `1`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
