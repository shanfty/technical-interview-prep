# Multiply Strings

Given two non-negative integers represented as strings, return their product, also represented as a string. Do not convert the inputs directly to integer types or use a big-integer library.

Examples: `"2"` times `"3"` returns `"6"`; `"123"` times `"456"` returns `"56088"`; any factor equal to `"0"` produces `"0"`.
