# Redundant Connection

Given a connected undirected graph that started as a tree with nodes labeled `1` through `n` and then received one extra edge, return an edge that can be removed so the graph becomes a tree again. If multiple answers exist, return the one that appears last in the input.

Example: edges `[[1,2],[1,3],[2,3]]` return `[2,3]`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
