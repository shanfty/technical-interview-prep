# Binary Tree Maximum Path Sum

Given the root of a non-empty binary tree, return the maximum path sum. A path is a sequence of nodes connected by edges, may start and end at any nodes, and may not revisit a node.

Example: `[-10,9,20,null,null,15,7]` returns `42`; `[1,2,3]` returns `6`.
