# Combination Sum II

Given an array of candidates that may contain duplicates and a target integer, return all unique combinations whose values sum to the target. Each candidate may be used at most once. The result may be returned in any order.

Examples: candidates `[10,1,2,7,6,1,5]`, target `8` returns `[[1,1,6],[1,2,5],[1,7],[2,6]]`; candidates `[2,5,2,1,2]`, target `5` returns `[[1,2,2],[5]]`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
