# Cheapest Flights Within K Stops

There are `n` cities and directed flights `[from, to, price]`. Return the cheapest price from `src` to `dst` using at most `k` stops, or `-1` if no such route exists.

Examples: flights `[[0,1,100],[1,2,100],[0,2,500]]`, `src=0`, `dst=2`, `k=1` returns `200`; with `k=0` returns `500`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
