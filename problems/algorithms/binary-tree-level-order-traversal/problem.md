# Binary Tree Level Order Traversal

Given the root of a binary tree, return its level-order traversal: the values of nodes from left to right, grouped by depth.

Examples: `[3,9,20,null,null,15,7]` returns `[[3],[9,20],[15,7]]`; an empty tree returns `[]`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
