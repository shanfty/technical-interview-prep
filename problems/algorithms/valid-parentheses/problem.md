# Valid Parentheses

Given a string containing only `()[]{}`, determine whether it is valid. Brackets must close in the correct order, and every opening bracket must have a matching closing bracket.

Examples: `"()"` returns `true`; `"()[]{}"` returns `true`; `"(]"` returns `false`; `"([)]"` returns `false`.
