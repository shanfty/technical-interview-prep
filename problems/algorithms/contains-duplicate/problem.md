# Contains Duplicate

Given an integer array `nums`, return `true` if any value appears at least twice in the array, and return `false` if every value is distinct.

Examples: `[1, 2, 3, 1]` returns `true`; `[1, 2, 3, 4]` returns `false`; `[1, 1]` returns `true`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
