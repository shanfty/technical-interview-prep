# Time Based Key-Value Store

Design a time-based key-value data structure that supports `set(key, value, timestamp)` and `get(key, timestamp)`. `get` returns the value set at the largest timestamp less than or equal to the requested timestamp, or the empty string if no such value exists.

Timestamps for a given key are strictly increasing.
