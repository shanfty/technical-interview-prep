# Reorder List

Given the head of a singly linked list `L0 → L1 → … → Ln`, reorder it to `L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → …`. You may not change node values, only node links.

Examples: `[1,2,3,4]` becomes `[1,4,2,3]`; `[1,2,3,4,5]` becomes `[1,5,2,4,3]`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
