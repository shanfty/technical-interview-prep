# Subsets

Given an integer array `nums` containing unique values, return all possible subsets, including the empty subset and the full array. The result may be returned in any order.

Examples: `[1,2,3]` produces `[]`, `[1]`, `[2]`, `[3]`, `[1,2]`, `[1,3]`, `[2,3]`, and `[1,2,3]`; `[]` produces `[[]]`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
