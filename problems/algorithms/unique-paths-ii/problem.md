# Unique Paths II

Given an `m x n` grid with obstacles marked `1` and open cells marked `0`, return the number of paths from the top-left to bottom-right cell when movement is limited to right or down. The start and end cells may be open by contract.

Examples: `[[0,0,0],[0,1,0],[0,0,0]]` returns `2`; `[[0,1],[0,0]]` returns `1`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
