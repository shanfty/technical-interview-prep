# Design Add and Search Words Data Structure

Design a data structure that supports adding lowercase words and searching for words. A search pattern may contain `.` characters, each of which matches any single lowercase letter.

Example operations: add `bad`, `dad`, and `mad`; search `pad` is `false`; search `bad` is `true`; search `.ad` is `true`; search `b..` is `true`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
