# Merge Intervals

Given an array of intervals, merge all overlapping intervals and return an array of the non-overlapping intervals that cover the same ranges.

Examples: `[[1,3],[2,6],[8,10],[15,18]]` becomes `[[1,6],[8,10],[15,18]]`; `[[1,4],[4,5]]` becomes `[[1,5]]`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
