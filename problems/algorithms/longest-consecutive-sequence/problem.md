# Longest Consecutive Sequence

Given an unsorted array of integers `nums`, return the length of the longest consecutive elements sequence. The sequence elements need not be adjacent in the input array.

Examples: `[100,4,200,1,3,2]` returns `4`; `[0,3,7,2,5,8,4,6,0,1]` returns `9`; `[]` returns `0`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
