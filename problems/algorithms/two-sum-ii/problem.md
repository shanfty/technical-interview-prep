# Two Sum II - Input Array Is Sorted

Given a 1-indexed array of integers `numbers` sorted in non-decreasing order and a target integer, return the two indices of numbers that add up to the target. Exactly one solution exists, indices are distinct, and the result must use 1-based indexing.

Examples: `[2,7,11,15]`, target `9` returns `[1,2]`; `[2,3,4]`, target `6` returns `[1,3]`; `[-1,0]`, target `-1` returns `[1,2]`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
