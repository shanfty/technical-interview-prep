# Kth Largest Element in an Array

Given an integer array `nums` and an integer `k`, return the `k`th largest element in the array. The rank counts duplicates, so the `k`th largest element is not necessarily distinct.

Examples: `[3,2,1,5,6,4]`, `k = 2` returns `5`; `[3,2,3,1,2,4,5,5,6]`, `k = 4` returns `4`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
