# N-Queens

Place `n` queens on an `n x n` chessboard so that no two queens attack each other. Return all distinct valid board configurations. Each configuration uses `Q` for a queen and `.` for an empty square.

Examples: `n = 1` returns one board; `n = 4` returns two configurations; `n = 2` returns no configurations.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
