# Task Scheduler

Given a list of tasks represented by uppercase letters and a non-negative cooling interval `n`, return the minimum number of time units required to execute all tasks. The same task must have at least `n` other intervals between executions; idle intervals are allowed.

Examples: tasks `[A,A,A,B,B,B]`, `n = 2` returns `8`; tasks `[A,A,A,B,B,B]`, `n = 0` returns `6`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
