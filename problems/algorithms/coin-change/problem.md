# Coin Change

Given an array of coin denominations and an integer `amount`, return the fewest number of coins needed to make that amount. You may use each denomination unlimited times. Return `-1` if the amount cannot be formed.

Examples: coins `[1,2,5]`, amount `11` returns `3`; coins `[2]`, amount `3` returns `-1`; amount `0` returns `0`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
