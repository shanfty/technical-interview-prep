# Valid Anagram

Given two strings `s` and `t`, return `true` if `t` is an anagram of `s`, and `false` otherwise. An anagram uses every character from the original string exactly once, with the same frequencies.

Examples: `("anagram", "nagaram")` returns `true`; `("rat", "car")` returns `false`; strings with different lengths return `false`.

Assume the strings contain lowercase English letters.
