# Minimum Window Substring

Given strings `s` and `t`, return the shortest substring of `s` that contains every character in `t`, including duplicate occurrences. If no such substring exists, return the empty string. If multiple shortest windows exist, return any one.

Examples: `s = "ADOBECODEBANC"`, `t = "ABC"` returns `"BANC"`; `s = "a"`, `t = "a"` returns `"a"`; `s = "a"`, `t = "aa"` returns `""`.
