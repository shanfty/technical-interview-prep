# Decode Ways

A message containing letters `A-Z` is encoded as `1-26`. Given a string of digits, return the number of ways to decode it. A digit `0` cannot be decoded by itself, and leading zeroes are invalid.

Examples: `"12"` returns `2` (`AB` or `L`); `"226"` returns `3`; `"06"` returns `0`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
