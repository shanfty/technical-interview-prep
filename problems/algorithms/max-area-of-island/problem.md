# Max Area of Island

Given an `m x n` binary matrix `grid`, return the maximum area of an island. An island is a group of horizontally or vertically connected `1` cells. If there is no island, return `0`.

Examples: `[[0,0,0],[0,1,1],[0,1,0]]` has maximum area `3`; an all-water grid returns `0`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
