# Find the Duplicate Number

Given an array `nums` containing `n + 1` integers where each integer is in the range `[1,n]`, return the only repeated number. The duplicate may appear more than once.

Examples: `[1,3,4,2,2]` returns `2`; `[3,1,3,4,2]` returns `3`; `[3,3,3,3,3]` returns `3`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
