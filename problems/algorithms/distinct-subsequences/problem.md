# Distinct Subsequences

Given strings `s` and `t`, return the number of distinct subsequences of `s` that equal `t`. A subsequence preserves order but may omit characters.

Examples: `s = "rabbbit"`, `t = "rabbit"` returns `3`; `s = "babgbag"`, `t = "bag"` returns `5`.
