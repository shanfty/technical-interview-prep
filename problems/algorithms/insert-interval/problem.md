# Insert Interval

Given a list of non-overlapping intervals sorted by start time and a new interval, insert the new interval while preserving sorted order and merging any overlaps.

Examples: `[[1,3],[6,9]]` with `[2,5]` becomes `[[1,5],[6,9]]`; `[[1,2],[3,5],[6,7],[8,10],[12,16]]` with `[4,8]` becomes `[[1,2],[3,10],[12,16]]`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
