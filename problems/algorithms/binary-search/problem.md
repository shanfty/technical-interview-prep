# Binary Search

Given a sorted array of integers `nums` and an integer `target`, return the index of `target` if it is present; otherwise return `-1`.

Examples: `[-1,0,3,5,9,12]`, target `9` returns `4`; the same array with target `2` returns `-1`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
