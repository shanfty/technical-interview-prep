# Product of Array Except Self

Given an integer array `nums`, return an array `answer` such that `answer[i]` equals the product of every element of `nums` except `nums[i]`.

The product of any prefix or suffix fits in a 32-bit integer. Do not use division.

Examples: `[1,2,3,4]` returns `[24,12,8,6]`; `[-1,1,0,-3,3]` returns `[0,0,9,0,0]`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
