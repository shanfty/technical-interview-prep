# Reverse Nodes in K-Group

Given the head of a linked list, reverse the nodes of the list `k` at a time and return the modified list. Nodes in a final group with fewer than `k` nodes must remain in their original order.

Examples: `[1,2,3,4,5]`, `k = 2` becomes `[2,1,4,3,5]`; `k = 3` becomes `[3,2,1,4,5]`; `k = 1` is unchanged.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
