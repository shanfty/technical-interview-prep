# Course Schedule

There are `numCourses` courses labeled from `0` to `numCourses - 1`. Prerequisite pairs `[a,b]` mean course `b` must be completed before course `a`. Return `true` if it is possible to finish all courses, and `false` if prerequisites contain a cycle.

Examples: `numCourses = 2`, prerequisites `[[1,0]]` returns `true`; `[[1,0],[0,1]]` returns `false`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
