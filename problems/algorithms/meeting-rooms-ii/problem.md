# Meeting Rooms II

Given an array of meeting time intervals where each interval is `[start, end]`, return the minimum number of conference rooms required to hold all meetings.

Examples: `[[0,30],[5,10],[15,20]]` returns `2`; `[[7,10],[2,4]]` returns `1`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
