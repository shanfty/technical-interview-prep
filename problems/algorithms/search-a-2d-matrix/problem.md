# Search a 2D Matrix

Write a function that searches for a target value in an `m x n` matrix. Each row is sorted in ascending order, and the first integer of each row is greater than the last integer of the previous row. Return `true` if the target exists and `false` otherwise.

Examples: `[[1,3,5,7],[10,11,16,20],[23,30,34,60]]`, target `3` returns `true`; target `13` returns `false`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
