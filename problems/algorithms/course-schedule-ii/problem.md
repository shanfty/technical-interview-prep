# Course Schedule II

There are `numCourses` courses labeled from 0 to `numCourses - 1` and prerequisite pairs `[course, prerequisite]`. Return an ordering of courses that permits completing all courses, or an empty array if impossible. Any valid ordering is acceptable.

Source: https://neetcode.io/problems/course-schedule-ii

Implement `Solution.findOrder(int numCourses, int[][] prerequisites)`.
