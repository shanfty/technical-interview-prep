# House Robber II

Houses are arranged in a circle, so the first and last houses are adjacent. Given the amount of money in each house, return the maximum amount that can be robbed without robbing adjacent houses.

Examples: `[2,3,2]` returns `3`; `[1,2,3,1]` returns `4`; `[1,2,3]` returns `3`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
