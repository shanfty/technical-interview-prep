# Non-overlapping Intervals

Given an array of intervals, return the minimum number of intervals you need to remove to make the rest non-overlapping. Intervals that touch at an endpoint are non-overlapping.

Examples: `[[1,2],[2,3],[3,4],[1,3]]` returns `1`; `[[1,2],[1,2],[1,2]]` returns `2`; `[[1,2],[2,3]]` returns `0`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
