# Container With Most Water

Given an integer array `height`, choose two vertical lines at different indices to form a container with the x-axis. Return the maximum amount of water the container can hold.

Example: `[1,8,6,2,5,4,8,3,7]` returns `49`; `[1,1]` returns `1`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
