# Two Sum

Given an array of integers `nums` and an integer `target`, return the indices of two distinct elements whose values add up to `target`.

You may assume that exactly one valid pair exists. Return the two indices in any order.

Examples:

- `nums = [2, 7, 11, 15]`, `target = 9` returns `[0, 1]`.
- `nums = [3, 2, 4]`, `target = 6` returns `[1, 2]`.
- `nums = [3, 3]`, `target = 6` returns `[0, 1]`.

Constraints: `2 <= nums.length <= 10,000`; values and `target` are integers.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
