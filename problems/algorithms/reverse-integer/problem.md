# Reverse Integer

Given a signed 32-bit integer `x`, return `x` with its decimal digits reversed. If reversing `x` causes the value to fall outside the signed 32-bit range, return `0`.

Examples: `123` returns `321`; `-123` returns `-321`; `120` returns `21`; `1534236469` returns `0` because the reversed value overflows.
