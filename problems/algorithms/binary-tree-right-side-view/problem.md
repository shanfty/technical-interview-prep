# Binary Tree Right Side View

Given the root of a binary tree, imagine standing on its right side and return the values of the nodes visible from top to bottom.

Examples: `[1,2,3,null,5,null,4]` returns `[1,3,4]`; an empty tree returns `[]`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
