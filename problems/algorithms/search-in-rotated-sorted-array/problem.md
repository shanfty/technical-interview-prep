# Search in Rotated Sorted Array

Given an array of distinct integers sorted in ascending order and rotated at an unknown pivot, return the index of `target`, or `-1` if it is not present. The array was originally sorted in ascending order.

Examples: `[4,5,6,7,0,1,2]`, target `0` returns `4`; the same array with target `3` returns `-1`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
