# Spiral Matrix

Given an `m x n` matrix, return all elements in spiral order, starting at the top-left corner and proceeding clockwise around the boundaries toward the center.

Examples: `[[1,2,3],[4,5,6],[7,8,9]]` returns `[1,2,3,6,9,8,7,4,5]`; `[[1,2,3,4]]` returns `[1,2,3,4]`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
