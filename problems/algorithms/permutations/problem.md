# Permutations

Given an array `nums` of distinct integers, return all possible permutations. The result may be returned in any order.

Examples: `[1,2,3]` produces all six orderings; `[0,1]` produces `[[0,1],[1,0]]`; `[1]` produces `[[1]]`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
