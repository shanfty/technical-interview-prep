# Koko Eating Bananas

Koko has piles of bananas and can eat at integer speed `k` bananas per hour. Each hour she chooses one pile and eats up to `k` bananas. Return the minimum speed that lets her finish all piles within `h` hours.

Source: https://neetcode.io/problems/koko-eating-bananas

Implement `Solution.minEatingSpeed(int[] piles, int h)`.
