# Evaluate Reverse Polish Notation

Evaluate an arithmetic expression written in Reverse Polish Notation. Valid operators are `+`, `-`, `*`, and `/`. Integer division truncates toward zero. Operands and results fit in signed 32-bit integers.

Examples: `["2","1","+","3","*"]` returns `9`; `["4","13","5","/","+"]` returns `6`; `["10","6","9","3","+","-11","*","/","*","17","+","5","+"]` returns `22`.
