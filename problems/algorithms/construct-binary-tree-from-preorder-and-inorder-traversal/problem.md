# Construct Binary Tree from Preorder and Inorder Traversal

Given the preorder and inorder traversals of a binary tree with unique values, construct and return the tree.

Example: preorder `[3,9,20,15,7]` and inorder `[9,3,15,20,7]` reconstruct the tree `[3,9,20,null,null,15,7]`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
