# Merge Two Sorted Linked Lists

Given the heads of two sorted singly linked lists, merge them into one sorted linked list by reusing the existing nodes and return its head.

Examples: `[1,2,4]` and `[1,3,4]` produce `[1,1,2,3,4,4]`; two empty lists produce an empty list.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
