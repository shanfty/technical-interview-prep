# Reconstruct Itinerary

Given airline tickets represented by pairs `[from, to]`, reconstruct the itinerary in order and use all tickets exactly once. Start at `JFK`. If multiple valid itineraries exist, return the lexicographically smallest one.

Example: tickets `[[MUC,LHR],[JFK,MUC],[SFO,SJC],[LHR,SFO]]` return `[JFK,MUC,LHR,SFO,SJC]`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
