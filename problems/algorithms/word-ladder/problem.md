# Word Ladder

Given `beginWord`, `endWord`, and a dictionary `wordList`, return the length of the shortest transformation sequence from `beginWord` to `endWord`. Each step changes exactly one character, and every intermediate word must be in the dictionary. Return `0` if no sequence exists.

Examples: `"hit"` to `"cog"` with `["hot","dot","dog","lot","log","cog"]` returns `5`; without `"cog"` it returns `0`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
