# Encode and Decode Strings

Design an algorithm to encode a list of strings into one string and decode that string back to the original list. Strings may contain arbitrary characters, including delimiters used by the encoding format.

Examples: `["neet","code"]` must round-trip to the same list; `[]` and `[""]` must also round-trip exactly.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
