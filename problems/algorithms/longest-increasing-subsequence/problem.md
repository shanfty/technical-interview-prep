# Longest Increasing Subsequence

Given an integer array `nums`, return the length of the longest strictly increasing subsequence. A subsequence does not need to occupy contiguous positions.

Examples: `[10,9,2,5,3,7,101,18]` returns `4`; `[0,1,0,3,2,3]` returns `4`; `[7,7,7,7]` returns `1`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
