# Kth Smallest Element in a BST

Given the root of a binary search tree and an integer `k`, return the `k`th smallest value among all nodes. `k` is valid for the tree.

Example: `[3,1,4,null,2]`, `k = 1` returns `1`; the same tree with `k = 2` returns `2`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
