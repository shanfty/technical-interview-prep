# Top K Frequent Elements

Given an integer array `nums` and an integer `k`, return the `k` most frequent elements. The answer may be returned in any order.

You may assume the answer is unique.

Examples: `[1,1,1,2,2,3]`, `k = 2` returns the elements `{1,2}`; `[1]`, `k = 1` returns `{1}`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
