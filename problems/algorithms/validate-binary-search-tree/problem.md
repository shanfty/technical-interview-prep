# Validate Binary Search Tree

Given the root of a binary tree, determine whether it is a valid binary search tree. Every node in the left subtree must be strictly smaller than the node, and every node in the right subtree must be strictly larger; this rule applies recursively.

Examples: `[2,1,3]` is valid; `[5,1,4,null,null,3,6]` is invalid.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
