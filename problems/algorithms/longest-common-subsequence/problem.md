# Longest Common Subsequence

Given two strings `text1` and `text2`, return the length of their longest common subsequence. A subsequence preserves order but does not need to occupy contiguous positions.

Examples: `"abcde"` and `"ace"` return `3`; `"abc"` and `"abc"` return `3`; `"abc"` and `"def"` return `0`.
