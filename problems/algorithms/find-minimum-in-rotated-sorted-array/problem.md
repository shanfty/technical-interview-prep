# Find Minimum in Rotated Sorted Array

Given an array of distinct integers sorted in ascending order and rotated between one and `n` times, return the minimum element. The array was originally sorted in ascending order.

Examples: `[3,4,5,1,2]` returns `1`; `[4,5,6,7,0,1,2]` returns `0`; `[11,13,15,17]` returns `11`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
