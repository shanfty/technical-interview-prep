# Implement Trie (Prefix Tree)

Implement a trie with `insert`, `search`, and `startsWith` operations for lowercase English words. `search` returns whether a complete word exists; `startsWith` returns whether any inserted word begins with the prefix.

Example operations: insert `apple`, search `apple` is `true`, search `app` is `false`, startsWith `app` is `true`, insert `app`, then search `app` is `true`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
