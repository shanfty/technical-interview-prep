# Letter Combinations of a Phone Number

Given a string of digits from `2` to `9`, return all possible letter combinations that the digits could represent. Return the combinations in any order. The mapping follows a telephone keypad; `7` and `9` have four letters.

Examples: `"23"` returns the nine combinations from `ad` through `cf`; an empty input returns `[]`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
