# Happy Number

Write a function that determines whether a positive integer is happy. Repeatedly replace the number by the sum of the squares of its digits. If the process reaches `1`, the number is happy; if it enters a cycle that does not include `1`, it is not.

Examples: `19` returns `true`; `2` returns `false`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
