# Hand of Straights

Given an integer array `hand` and an integer `groupSize`, return `true` if the cards can be rearranged into groups of size `groupSize` where each group contains consecutive values. Every card must be used exactly once.

Examples: `hand = [1,2,3,6,2,3,4,7,8]`, `groupSize = 3` returns `true`; `hand = [1,2,3,4,5]`, `groupSize = 4` returns `false`.
