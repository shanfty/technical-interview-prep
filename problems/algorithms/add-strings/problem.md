# Add Strings

Given two non-negative integers represented as strings, return their sum, also represented as a string. Do not convert the inputs directly to integer types.

Examples: `"11"` plus `"123"` returns `"134"`; `"456"` plus `"77"` returns `"533"`; `"0"` plus `"0"` returns `"0"`.
