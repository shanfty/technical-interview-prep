# Partition Equal Subset Sum

Given a non-empty array of positive integers, determine whether it can be partitioned into two subsets whose sums are equal. Each element may be used in at most one subset.

Examples: `[1,5,11,5]` returns `true`; `[1,2,3,5]` returns `false`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
