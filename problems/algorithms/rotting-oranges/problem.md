# Rotting Oranges

In a grid, `0` is empty, `1` is a fresh orange, and `2` is a rotten orange. Every minute, fresh oranges adjacent four-directionally to rotten oranges become rotten. Return the minimum minutes until no fresh orange remains, or `-1` if impossible.

Examples: `[[2,1,1],[1,1,0],[0,1,1]]` returns `4`; `[[2,1,1],[0,1,1],[1,0,1]]` returns `-1`; `[[0,2]]` returns `0`.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
