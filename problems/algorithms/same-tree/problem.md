# Same Binary Tree

Given the roots of two binary trees, return `true` if the trees are structurally identical and all corresponding node values are equal; otherwise return `false`.

Examples: `[1,2,3]` and `[1,2,3]` are the same; `[1,2]` and `[1,null,2]` are different; two empty trees are the same.

Source: [NeetCode 150](https://neetcode.io/practice/practice/neetcode150)
